# v0.1 hand-drafted Buffett rubrics (archived)

Twenty rubrics drafted by hand before the two-stage pipeline existed, with their ad hoc schema, review questions, and the v0.2 audit whose findings (for example the `not_observable` outcome) shaped the pipeline schemas in `rubric_pipeline/schemas/`. Kept for reference only; the pipeline does not read these files, and `local_file` paths inside them use the old `buffett_corpus/` layout.
